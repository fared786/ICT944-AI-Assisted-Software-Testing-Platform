## Project Overview

This project investigates the requirements and proposed design of an
AI-assisted software testing practice platform.

The proposed platform is intended to help software testing learners practise
certification-style questions through structured feedback, explanation and
reasoning support, scoring, performance analytics, and identification of weak
knowledge areas.

## Assessment 1 Requirements

Assessment 1 will cover:

1. Project Charter and Stakeholder Register
2. Problem Statement and Business Analysis Report
3. Requirements Elicitation Report
4. Software Requirements Specification
5. Feasibility Study and Risk Register
6. Proposed high-level solution design
7. Weekly project progress and supervisor feedback

## Requirements Collection Method

Project requirements will be collected through structured analysis of:

- ICT944 Cybersecurity and Software Development Integrative Project Unit Outline
- AI-Assisted Software Testing Practice Platform Project Brief

No stakeholder interviews, surveys, or workshops are planned for this
assessment stage.

Requirements will be classified as:

- Explicit requirement — directly stated in the project document
- Inferred requirement — logically derived from the project document
- Proposed requirement — recommended during project analysis
- Assumption — used where the project document does not provide sufficient detail
